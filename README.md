# AHB_LITE_TO_APB_BRIDGE_VERIFICATION
SystemVerilog and UVM-based verification of an AHB-Lite to APB bridge, using a custom AHB-Lite master agent and a reusable APB slave agent from AVIP. Includes test sequences, protocol checks, and functional verification of bridge transactions, wait states, error handling, and data integrity.
